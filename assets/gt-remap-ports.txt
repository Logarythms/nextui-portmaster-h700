# gt-remap-ports.txt — launcher filenames (one per line, exact) of ports the
# pak preloads gt-input-remap.so for (F25). NextUI rc11 numbers the buttons
# correctly (F65), so what remains is the keyboard tier: gptokeyb's uinput
# device never reaches NextUI's SDL directly, so when no gptokeyb is running
# for one of these ports, the shim synthesizes SDL key events (and, from v3,
# keeps SDL_GetKeyboardState in sync for polling games) from the port's gptk
# as a fallback. See assets/gt-input-remap.c for the details. Users can
# extend this without rebuilding via a `use-remap-ports` file in the pak's
# userdata dir. Lines starting with # never match a filename and act as comments.
# On stick-equipped devices the shim also honors the gptk's left/right_analog lines (F53).
