# gt-remap-ports.txt — launcher filenames (one per line, exact) of ports the
# pak preloads gt-input-remap.so for (F25). These ports need the shim on
# NextUI-h700: either they read raw SDL joystick events (whose button indices
# sit +3 off the expected layout) or they read the keyboard, which gptokeyb's
# uinput device never reaches on NextUI — so the shim synthesizes SDL key
# events (and, from v3, keeps SDL_GetKeyboardState in sync for polling games)
# from the port's gptk. See assets/gt-input-remap.c for the details. Users can
# extend this without rebuilding via a `use-remap-ports` file in the pak's
# userdata dir. Lines starting with # never match a filename and act as comments.
